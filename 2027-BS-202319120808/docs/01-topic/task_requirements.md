# 任务要求：最低完成要求 + 拓展目标

> 本文件依据指导教师 2027 届毕业论文任务表（建议调整后的本科最低完成要求）制定，作为论文验收依据。每条要求给出可核查的验收标准。

- 学生：李钦颖　学号：202319120808
- 论文题目：基于 FreeRTOS 的多传感器智能环境监测与远程控制方法设计与实现
- 制定日期：2026-10-04

## 一、最低完成要求（Must，全部达成方可申请答辩）

| 编号 | 要求 | 验收标准 |
|---|---|---|
| MR-1 | 完成 STM32 + ESP8266 终端硬件 | 给出硬件连接图与物料清单；终端可稳定供电运行；ESP8266 成功接入 WiFi |
| MR-2 | 多传感器接入 | 至少接入 3 类环境传感器（如温湿度、光照、可燃气体/烟雾等），采集数据可通过串口/MQTT 查看，数据带时间戳与字段说明 |
| MR-3 | MQTT 通信与远程控制 | 遥测数据可发布至 Broker；订阅下行 Topic 可远程控制执行器（如继电器/风扇/LED），形成「上报—决策—下行—执行」闭环；Topic/QoS 设计有文档 |
| MR-4 | FreeRTOS 任务划分与优先级 | 至少包含采集、通信、控制、报警四类任务；给出任务清单（职责、优先级、栈大小、周期）与调度说明 |
| MR-5 | 任务间通信 | 消息队列 / 信号量至少一种用于任务间同步或数据传递，并在文档中说明选择理由 |
| MR-6 | 超限报警 | 实现阈值判断与报警（本地声/光 + MQTT 报警事件上报），阈值可配置 |
| MR-7 | 性能测试 | 完成并记录：①任务响应时间；②采样周期稳定性（周期抖动）；③MQTT 延迟与成功率；④报警响应时间。每项测试有样本量、方法与原始数据 |
| MR-8 | 异常工况测试 | 至少一种异常工况（网络中断/重连、传感器断线或超量程、MQTT 断连等）下的现象、系统处理与恢复验证 |
| MR-9 | Baseline 对比 | 实现裸机轮询版本作为 Baseline，与 FreeRTOS 版本在相同工况下对比至少一项性能指标 |
| MR-10 | 完整毕业论文 | 按学校规范完成开题、中期、定稿与查重，结构完整，数据可复现 |

## 二、拓展目标（Should / Nice to have）

| 编号 | 目标 | 验收标准 |
|---|---|---|
| EX-1 | 断网缓存与补传 | 网络中断期间数据本地缓存（带时间戳，不丢失或说明丢弃策略），恢复联网后按序补传；有中断—恢复对照实验 |

## 三、实验记录要求

每个实验必须在 `experiments/` 下使用独立目录（`baseline/`、`exp01/`、`exp02/`……），并在该目录中按 [experiments/README.md](../../experiments/README.md) 的统一模板撰写实验记录，至少包含：

- Experiment ID（EXP-编号，与基线的关系）
- Purpose（目的）
- Compared with（对照对象，如 Baseline）
- Configuration（软硬件配置与版本）
- Dataset / 数据来源（实测数据需记录采集条件）
- Random seed（涉及随机过程时必须固定并记录）
- Command（复现命令/操作步骤）
- Result（结果与原始数据位置）
- Conclusion（结论）
- Problems（遇到的问题与处理）
