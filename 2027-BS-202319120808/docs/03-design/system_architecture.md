# 系统架构设计

> 版本 v0.1（2026-10-04 骨架，随 S2 阶段细化）。配套架构图放 `figures/`。

## 1. 系统概述

系统由环境监测终端（STM32 + FreeRTOS + 多传感器 + 执行器）、WiFi 通信模块（ESP8266）、MQTT Broker 与上位机/云平台组成，实现环境数据周期采集、阈值超限报警、MQTT 遥测上报与远程控制。

## 2. 硬件架构

- 主控板：STM32（型号待定）；
- 通信模块：ESP8266，UART 连接（标明 USART 与波特率，待定稿）；
- 传感器接入：I2C / 单总线 / ADC，附引脚分配表（待补）；
- 执行器：GPIO → 驱动电路 → 继电器/LED/蜂鸣器/风扇；
- 供电与隔离、调试接口（SWD、串口）说明待补。

## 3. 软件分层

```text
应用层    采集任务 / 处理任务 / 报警任务 / 控制任务 / 通信任务
服务层    FreeRTOS 调度、队列、信号量/事件组、互斥量、软件定时器、看门狗
驱动层    传感器驱动、执行器驱动、ESP8266 AT 驱动
HAL/寄存器 STM32 HAL/LL、CubeMX 生成代码（单独标识，非本人原创部分需登记）
```

## 4. 任务模型

| 任务 | 优先级（初定） | 周期/触发 | 栈大小（待定） | 输入 | 输出 |
|---|---|---|---|---|---|
| SensorTask | 高 | 1 s 周期 | 待标定 | 传感器原始值 | 数据帧 → xQueueSensor |
| ProcessTask | 中高 | 队列阻塞 | 待标定 | xQueueSensor | 报警事件；处理后数据 → xQueueTx |
| AlarmTask | 最高 | 事件位 | 待标定 | 报警事件 | 声光动作；报警帧 → xQueueTx |
| CommTask | 中 | 队列/事件驱动 | 待标定 | xQueueTx；AT 响应 | MQTT 发布；下行指令 → xQueueCmd；连接状态 |
| CtrlTask | 中 | xQueueCmd | 待标定 | 下行指令 | 执行器动作；回执帧 → xQueueTx |

共享资源保护：UART（ESP8266）、I2C 总线使用互斥量；采样时间基准使用软件定时器/Tick。

## 5. 通信设计

- MQTT Topic 与 JSON 字段见技术路线第 4 节；字段表维护在 `data/metadata/`；
- 断网处理：连接状态机（未连接→连接中→已连接→重连中），拓展目标为断网缓存与补传。

## 6. 配置管理

- 任务参数、报警阈值、MQTT 参数、引脚映射集中放 `configs/`，实验时以配置快照 + git 提交号保证可复现。
