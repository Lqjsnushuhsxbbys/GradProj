# 实验设计

> 版本 v0.1（2026-10-04）。实验记录模板与编号规则见 `experiments/README.md`；实验与任务要求的对应关系见 `docs/01-topic/task_requirements.md`。

## 1. 实验总体设计

- 对照组：裸机轮询 Baseline（相同硬件、相同传感器与采样周期）；
- 实验组：FreeRTOS 多任务版本；
- 控制变量：硬件平台、供电、传感器、采样周期、Broker、网络环境、测试时长；
- 每轮实验固定配置快照（git commit + configs 副本）；涉及重连退避等随机过程时固定随机种子并记录；
- 测量手段双轨：终端 GPIO 翻转 + 逻辑分析仪/示波器测系统内时间；PC 订阅脚本打毫秒级时间戳测端到端时间。

## 2. 指标定义

| 指标 | 定义 | 统计量 |
|---|---|---|
| 任务响应时间 | 触发事件到任务首条执行语句（GPIO 翻转）的时间 | 均值、P95、最大 |
| 采样周期稳定性 | 相邻两次采样间隔与设定周期之差 | 均值、标准差、最大偏差、丢采次数 |
| MQTT 延迟 | 终端发布时间戳到订阅端收包时间戳之差 | 均值、P95、最大 |
| MQTT 成功率 | 订阅端收包数 / 终端发布数 | 百分比 + 失败分类 |
| 报警响应时间 | 物理量越限到本地动作、报警消息到达平台的两段时间 | 均值、最大 |

## 3. 计划实验

### EXP-001 裸机轮询 Baseline 性能摸底
- 目的：得到裸机轮询架构下采样周期、事件响应的基准数据；
- 对照：无（作为后续基线）；
- 工况：单传感器/多传感器两档，连续运行 ≥ 30 min；
- 输出：周期与响应原始数据、统计值。

### EXP-002 FreeRTOS 任务响应时间与采样周期稳定性
- 目的：验证任务划分、优先级与队列/信号量设计的实时性；
- 对照：EXP-001；
- 变量：任务负载档位（是否并发通信/控制）、采样周期（如 0.5 s / 1 s / 2 s）；
- 输出：响应时间分布、周期抖动统计。

### EXP-003 MQTT 延迟与成功率
- 目的：量化上报链路质量；
- 对照：EXP-002 同周期数据；可分 QoS0/QoS1；
- 方法：每档发布 ≥ 1000 条（具体样本量在记录中说明），记录延迟与丢包；
- 输出：延迟分布、成功率、失败原因分类。

### EXP-004 超限报警响应时间
- 目的：量化从越限到本地动作/平台收到报警的时间；
- 方法：可控方式注入越限（标准信号源/手动改变环境），重复 ≥ 30 次；
- 输出：两段响应时间统计、误报/漏报记录。

### EXP-005 异常工况测试
- 目的：至少验证一种异常工况的检测、处理与恢复；
- 工况：① 断开 WiFi/路由器（MQTT 掉线与重连）；② 传感器断线/读数超量程；二选一必做，另一个鼓励完成；
- 记录：注入时刻、系统现象、重连/恢复时间、数据丢失与缓存情况。

### EXP-006（拓展）断网缓存与补传
- 目的：验证 EX-1；中断指定时长后恢复网络，核对补传数据条数、顺序与时间戳完整性。

### EXP-007（拓展）资源占用与任务抖动综合分析
- 目的：验证 EX-2；统计 CPU 占用率、栈高水位/堆使用，以及不同优先级配置下的抖动变化。

## 4. 数据管理

- 原始数据放 `results/logs/` 或对应 `experiments/expNN/`，表格汇总放 `results/tables/`，图放 `results/figures/`；
- 每份数据在 `data/metadata/` 有字段说明；实验记录必须链接到原始数据路径。
