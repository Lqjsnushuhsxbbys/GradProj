## 一、研究问题

1. 研究对象：以 STM32 为主控、ESP8266 为联网模块，运行 FreeRTOS 的多传感器智能环境监测与远程控制系统，涵盖环境数据采集、超限报警、MQTT 通信与远程控制执行。
2. 当前问题：传统裸机轮询方式在多传感器采集、阈值报警、网络通信与远程控制并发执行时，任务耦合严重、实时性与稳定性不足；断网、传感器异常等工况缺少规范处理；系统性能也缺少量化测试与评估。
3. 本论文解决的问题：设计并实现基于 FreeRTOS 的多任务软件架构（任务划分、优先级、消息队列/信号量同步），完成多传感器采集、超限报警、MQTT 上报与远程控制闭环；对任务响应时间、采样周期稳定性、MQTT 延迟/成功率和报警响应进行量化测试，并至少针对一种异常工况完成验证与分析。

## 二、最低完成要求

- [ ] Baseline / 基础系统：完成 STM32 + ESP8266 终端硬件，接入多种环境传感器（如温湿度、光照、可燃气体/烟雾等），跑通 MQTT 上报与远程控制链路，并实现裸机轮询版本作为对照基线
- [ ] 核心方法或关键机制：明确 FreeRTOS 任务划分与优先级（采集任务、通信任务、控制任务、报警任务等）；至少使用一种任务间通信机制（消息队列 / 信号量）；实现阈值判断与超限报警

## 四、技术路线

总体流程：多传感器数据由 STM32 在 FreeRTOS 采集任务中周期采样，经消息队列/信号量在采集、处理、通信、控制、报警等任务间传递；ESP8266 负责 WiFi 联网，通过 MQTT 协议向 Broker 上报遥测数据与报警事件，并订阅下行远程控制指令驱动执行器；上位机/云平台完成数据展示与远程控制。在此基础上完成实时性、通信质量与异常工况测试。

详细技术路线见：[docs/01-topic/technical_route.md](docs/01-topic/technical_route.md)
