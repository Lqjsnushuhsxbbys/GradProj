# data 目录说明

本目录存放实验相关数据，**不得提交未说明来源或体积过大的二进制数据**。

## 子目录

- `metadata/`：数据字段定义、数据字典、采集条件说明；
- `samples/`：少量可公开的示例数据（完整原始数据如过大，注明获取方式或存储位置）。

## 数据规范

1. 每份数据文件须能在 `metadata/` 找到字段说明（名称、单位、取值范围、含义）；
2. 实测数据文件名建议：`EXP编号_场景_日期.csv`，如 `EXP-003_qos1_1s_20270215.csv`；
3. 数据须记录采集时间、采集人、硬件版本、固件 commit、环境条件；
4. 涉及随机过程的实验同时记录随机种子；
5. 大文件不入库，使用网盘/发布版附件并在此登记链接与校验值。
